# Online Learning Platform

A simple **JSP + Servlet + JDBC** web application that provides user registration, login, and course management.  
This project is beginner-friendly and demonstrates how to build a Java-based web application using JSP pages, Servlets, and MySQL database.


Features
- User Registration  
- User Login  
- Add Courses  
- View Courses  
- Session-based Authentication  
- JDBC Connectivity (MySQL)

Technologies Used

Frontend - JSP (Java Server Pages) and CSS

Backend - Java Servlets and JDBC

Database - MySQL
